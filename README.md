# devops247-online Homebrew tap

```sh
brew install devops247-online/tap/shellclear
```

or

```sh
brew tap devops247-online/tap
brew install shellclear
```

## Formulae

| Formula | Description |
|---|---|
| [shellclear](https://github.com/devops247-online/shellclear) | Find and mask secrets in shell history |

Formulae build from source and are published automatically by each
project's release workflow after `brew test` and `brew audit --strict` pass.
